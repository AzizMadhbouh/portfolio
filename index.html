Things I've built

01

CI Logs Classifier

End-to-end CI failure intelligence: ingests Jenkins builds, classifies failures with a fine-tuned ModernBERT model, scores severity (LLM + deterministic policy fallback), stores everything in PostgreSQL and visualizes it in Grafana.

  • 0.77 macro-F1
  • 14,320 eval logs
  • 84 passed
  • PyTorch
  • ModernBERT
  • PostgreSQL
  • Grafana
  • Docker
  • Jenkins
02

EV Analytics — Spark & Hadoop

Distributed analytics pipeline over electric-vehicle registration data on a Dockerized HDFS + YARN + Spark cluster (1 NameNode, 3 DataNodes, 3 workers), computing seven aggregations with PySpark.

  • 280k rows
  • 3 DataNodes
  • 7 analyses
  • PySpark
  • Hadoop
  • HDFS
  • YARN
  • Docker Compose
03

MapReduce Purchases Analytics

MapReduce pipeline built on Hadoop Streaming that computes total sales and transaction counts per product category across 4.1 million retail records, with a Dockerized HDFS cluster.

  • 4.1M records
  • 18 categories
  • 201 MB via LFS
  • MapReduce
  • Hadoop Streaming
  • HDFS
  • Python
04

Medical No-Show Prediction

Healthcare analytics project predicting missed appointments. Compares a logistic-regression baseline against a class-balanced random forest built on a scikit-learn pipeline, with an honest read on class imbalance.

  • 110k records
  • 28.5% no-show rate
  • 0.53 macro-F1 (RF)
  • scikit-learn
  • Pandas
  • Seaborn
  • Jupyter
